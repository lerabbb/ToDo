# ToDo-list

Приложение ToDo-list для платформы iOS. Есть возможность просматривать список задач, создавать/удалять задачи, редактировать статус задачи и т.д.
* Хранилище: Core Data
* ЯП: Swift
* Использование Grand Central Dispatch и UIKit
* Архитектура: Clean Swift.

референс дизайна: https://www.figma.com/community/file/1083383246788717048
